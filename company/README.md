Tailored materials for specific companies you're interviewing with.

## Adding a New Company

1. Create a folder: `mkdir <company>/`
2. Create a README with company-specific strategy
3. Add files for:
   - **profile.md** — Your experience and why you're a fit for this role
   - **context.md** — Domain knowledge (product, tech stack, business)
   - **questions.md** — Questions to ask in interviews
   - **strategy.md** — Key themes and interview strategy (optional)

4. Reference shared materials:
   - [[STAR Stories](../star_stories/)] for behavioral questions
   - [[Leadership](../leadership/)] for management philosophy
   - [[Self-Introduction](../self-introduction/)] for personal pitch
   - [[Projects](../project-deep-dive/)] for technical depth
