## Adding a post

1. Put it in the topic sub-folder (create one if none fits, with its own `README.md`).
2. File name: short `snake_case`, no dates (e.g. `eval_driven_development.md`); put the date in the post's subtitle.
3. Add a row to the topic's `README.md` and update the table above.
4. Link to study notes with relative paths (from a topic folder, the repo root is `../../`).
